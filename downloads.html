ZDOS Linux

Scarica la ISO dal repository ufficiale ZDOS. Ogni release pubblicata include il checksum SHA-256 da verificare prima dell’avvio.

Scarica ISO ZDOS ⬇ Scarica checksum SHA-256 Tutte le release

Anteprima: l’ISO è una distribuzione minimale da avviare in QEMU. Il supporto hardware e l’installer BIOS sono sperimentali; non è un sistema desktop general-purpose.

Verifica e avvio su Ubuntu

sha256sum -c SHA256SUMS
qemu-system-x86_64 -cdrom zdos-linux-x86_64.iso -serial stdio -display none

Per build da sorgente, note della release e pacchetto container OCI, consulta il repository ZDOS ufficiale.
